# Notice

## What this repository contains

Original work. The writing rules in `skills/writing/first-read/`,
`integrations/claude/output-styles/`, and `docs/first-read/PROMPT.md` are our
own wording.

The rules are adapted from ASD-STE100 Simplified Technical English, Issue 9.
A citation such as `(3.5)` gives the rule number in that specification, so that
a reader can compare a rule here with the rule there. The citations are
references. They are not quotations.

## What this repository does not contain

No part of the ASD-STE100 specification. Not the text, not the writing rules as
written there, and not the dictionary of 2195 entries.

The specification and any extraction of it belong to the Aerospace, Security
and Defence Industries Association of Europe (ASD), which holds the copyright
and grants free use only to a specified list of organizations. That material
lives outside this repository. `.gitignore` keeps a guard against a file of
either kind, so that nobody adds one by mistake.

"ASD-STE100" and "Simplified Technical English" are European Union registered
trademarks owned by ASD. This project is not an ASD product. ASD does not
endorse it.

legal obligations or rights. The same is true of this project.
